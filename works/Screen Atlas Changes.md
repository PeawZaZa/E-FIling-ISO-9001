## ประวัติฉบับเต็มก่อนลดขอบเขต

ปรับเฉพาะ Screen Atlas.html โดยใช้ SRS_v1.md เป็นฐาน ภาพเป็นแบบร่าง ไม่ใช่ระบบสิทธิ์หรือธุรกรรมจริง

- เก็บรหัสหน้าจอเดิม เพิ่ม A07 ตรวจรับ/ทบทวน, A08 ติดตาม/ปิด DAR, B06 จัดทำแผน, B07 อนุมัติแผน, B08 ดำเนินการ, B09 ตรวจ/ปิดใบ, B10 รายงาน
- รวม 21 มุมมองหน้าจอและ 1 การ์ดส่วนเชื่อมต่อ ครอบคลุม 28 Use Case โดยหนึ่งหน้าจอรองรับหลาย Use Case ได้
- จับคู่ UC/FR/AC ใหม่ตามเนื้อหา SRS ไม่แปลงรหัสเก่าด้วยการเติมขีด
- เลือกบทบาทใช้งานครั้งละหนึ่งและแยกบุคคลแก้ไข/ตรวจ/ปิดใบ
- วงจรใบคำร้อง 8 สถานะภาษาไทย แยกเกินกำหนดออกจากสถานะ และแยกกรอบเวลาแผนรวมจากกำหนดรายขั้น
- DAR หกประเภท แยกตรวจรับ ทบทวน อนุมัติ ประกาศใช้ แจกจ่าย/เรียกคืน และตรวจครบก่อนปิด
- แยกมอบหมายรับทราบจากยืนยันรับทราบต่อฉบับ
- เปลี่ยน Integration API node เป็นการ์ดข้อมูลภายใน ไม่ใช่หน้าจอทางผ่าน
- ถอด API/Entities และ TC/SC เก่าที่ไม่ได้ยืนยัน หลีกเลี่ยงนำไปเข้าใจเป็นสัญญาส่วนเชื่อมต่อหรือหลักฐานทดสอบ
- เพิ่มการกรองกลุ่มและลิงก์ข้ามหน้าจอ ปุ่มธุรกรรมในภาพเป็น disabled เพื่อไม่แสร้งว่าบันทึกได้จริง

## ประเด็นที่ยังไม่ตัดสินแทน SRS

1. UC-B-10/§4.31 กับ Preconditions/BR-B-12/AC-B-19 เรื่องผู้อนุมัติแผน
2. จำนวนผู้ลงนามปิดใบ และเงื่อนไข Two-Step กับ UC-B-13
3. UC-B-12 Success Postconditions/AC-B-23 กับ §4.31 เรื่องส่งกลับดำเนินการหรือวิเคราะห์สาเหตุ ภาพแสดงกรณีไม่มีประสิทธิผลกลับวิเคราะห์ตาม Alternate A1 และไม่เพิ่มปุ่มผลไม่ครบถ้วนเอง
4. UC-B-08 A3 กับ E2 เรื่องเปิดใบโดยยังไม่มีผู้รับผิดชอบ ภาพตัวอย่างใช้ผู้รับผิดชอบครบ
5. อำนาจมอบหมายรับทราบ รายละเอียด DAR ประเภทถือครอง และค่ากำหนดเวลาที่ยังรอยืนยัน
