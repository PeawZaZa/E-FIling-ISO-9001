ทิศทางล่าสุดสำหรับงาน 2 สัปดาห์
ใช้ mockup เป็นฐานและยึด Use Case ของโครงการ รวม 21 มุมมองด้านล่างเป็นข้อเสนอ 10 หน้าหลัก + 3 ป๊อปอัป เก็บการตรวจครบและปิด DAR (UC-A-12) ในหน้ารายละเอียด DAR เดิม รวมงานแจกจ่าย/เรียกคืนที่จำเป็นตามประเภท เป้าหมาย 23 Use Case พักงานรองโดยไม่ยุบหลักแยกหน้าที่ เลือกบทบาทในเดโมหมายถึงสลับเป็นคนตัวอย่าง พร้อมอีเมล/รหัสผ่าน
อ่านขอบเขตที่เสนอ ตารางบทบาท และที่มารหัสเอกสารจาก QP-2301-0107 Rev.02
Atlas ด้านล่างยังเป็นรายการอ้างอิงฉบับเต็ม ไม่ใช่รายการที่ต้องทำครบในรอบนี้

คงรหัสหน้าจอเดิมและเพิ่มมุมมองที่ขาด ครอบคลุม Use Case 28 ตัวของสองโมดูลในระบบเดียวกัน ภาพเป็นข้อมูลสมมติและปุ่มธุรกรรมเป็นตัวอย่างที่กดบันทึกไม่ได้ ไม่ได้จำลองระบบสิทธิ์จริง

อ่านชื่อหน้าจอ → ภาพตัวอย่าง → เงื่อนไข → Use Case และผู้ทำการจาก SRS สีส้มคือข้อความที่ยังต้องยืนยัน การจับคู่ครบไม่ได้หมายความว่าข้อกำหนดผ่าน Baseline แล้ว
