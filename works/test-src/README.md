# Test Case Checklist

เปิด `../Test Cases.html` โดยตรง ไม่ต้องเปิด server และไม่มี external dependency
173 เคส: พร้อมทดสอบ 121, ยังไม่พัฒนา 47, รอข้อยุติกฎงาน 5 ตามสถานะเมื่อ 19 กันยายน 2569
ทุกผลเริ่มเป็นยังไม่ทดสอบ การพร้อมทดสอบไม่ใช่การผ่านทดสอบ

## ใช้งาน

1. กรองหมวดและความพร้อม เปิดชื่อเคสอ่านเงื่อนไข/ข้อมูล/ขั้นตอน/ผลคาดหวัง
2. ทำตามขั้นตอนแล้วติ๊กผ่าน หรือเลือกไม่ผ่าน/ติดขัด บันทึกชื่อผู้ทดสอบ วันที่ ผลจริง และเลขปัญหาในหมายเหตุ
3. เมื่อพัฒนาเสร็จ เปลี่ยนความพร้อมเป็นพร้อมทดสอบก่อนติ๊กผ่าน; หากเคยรอกฎงานให้บันทึกมติและที่มาไว้ด้วย
4. ผลบันทึกใน localStorage ของ browser นี้เท่านั้น ส่งออก JSON สำรองก่อนเปลี่ยน browser ย้ายไฟล์ หรือล้างข้อมูล
5. นำเข้าต้องเป็น schema/catalog รุ่นเดียวกัน มีรหัสครบทุกเคส; ตรวจข้อมูลทั้งหมดก่อนแทนผล และถามยืนยัน
6. พิมพ์เฉพาะรายการที่กรอง โดยขยายรายละเอียดให้อัตโนมัติ ส่วนยอดสรุปยังเป็นยอดรวมทั้ง MVP

JSON ที่ส่งออกจากหน้านี้เป็นผลทดสอบ ไม่ใช่ฟีเจอร์ส่งออกรายงานธุรกิจของแอป
หาก browser ไม่อนุญาต localStorage ผลยังเปลี่ยนในหน้าได้แต่ต้องส่งออกก่อนปิดหน้า
ไม่มีการส่งข้อมูลออกเครือข่าย ไม่มีการอ่านผล automated test มาติ๊กผ่านเอง

## แก้ไขและสร้างใหม่

`catalog.py` เป็นต้นทางเนื้อหา สร้าง `cases.json`; `template.html` เป็นต้นทาง UI; `build.py` ฝังข้อมูลให้เป็น HTML ไฟล์เดียว
รันจากรากโครงการ:

```powershell
python works/test-src/catalog.py
python works/test-src/build.py
```

ตัวสร้างตรวจรหัสเคสไม่ซ้ำ ช่องจำเป็นครบ และรหัสอ้างอิงทุกตัวมีใน SRS
ห้ามสลับลำดับ/ลบ/แทรกกลางเคสในหมวดเดิม เพราะรหัสอิงลำดับ ให้เพิ่มท้ายหมวดและตรวจรหัสก่อนสร้าง
หากเปลี่ยนความหมายหรือรหัสเคส ต้องเปลี่ยน catalog version ใน template และ KEY เพื่อไม่เอาผลเก่าไปผูกผิดเคส
การเปลี่ยนจำนวนเคสทำให้ไฟล์ผลเก่านำเข้าไม่ได้โดยตั้งใจ ต้องวางวิธีย้ายผลแยก ไม่ทิ้งข้อมูลเงียบ ๆ

## ตรวจหน้า HTML แล้ว

ทดสอบด้วย Chromium แยกจาก browser ผู้ใช้: ค่าเริ่มต้น 173 ยังไม่ทดสอบ, ติ๊ก/เปลี่ยนผล/หมายเหตุภาษาไทยและ HTML, reload, ค้นหา/กรอง/นับยอด, JSON export/import, ปฏิเสธ JSON/รุ่น/รหัส/ผลที่ผิดโดยไม่เปลี่ยนข้อมูลเดิม, ยืนยัน/ยกเลิกล้างผล, พิมพ์, หน้าจอ 390px และกรณี localStorage เขียนไม่ได้
ไม่พบ JavaScript error; ผลทดสอบหน้า HTML เหล่านี้ไม่ได้ถูกบันทึกเป็นผลผ่านของระบบ E-Filing
