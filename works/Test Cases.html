พักจาก MVP — ไม่นับในยอดด้านบน

  • UC-A-07 / FR-A-11 / AC-A-09: ยกเลิกเอกสารทั้งรายการ (ยังทดสอบการแทนฉบับเดิม)
  • UC-B-02: หน้าจัดการผู้ใช้เต็มรูปแบบ (ยังมีบัญชีเดโม FR-B-09 และตัวตนร่วม FR-B-06)
  • UC-B-03 / FR-B-08: หน้าค้นหาประวัติกลาง (ยังต้องบันทึก FR-B-07 และป้องกันการอ่าน/แก้/ลบ AC-B-06)
  • UC-B-16 / FR-B-41 / AC-B-27: ส่งออกรายงานธุรกิจ (ปุ่ม JSON หน้านี้เป็นผลทดสอบ ไม่ใช่ฟีเจอร์รายงานระบบ)
  • กราฟขั้นสูง FR-B-39.2–39.5, OCR, นำเข้าจำนวนมาก, สมัคร/ลืมรหัสผ่าน, แจ้งเตือนภายนอก และหน้าตั้งค่าครบชุด

การปิด DAR และ CAR ยังอยู่ในเป้าหมาย การรอกฎงานไม่เท่ากับตัดฟีเจอร์ออก ข้อมูลตัวเลข SLA/RPO/RTO ที่ยังไม่อนุมัติไม่ใช้ตัดสินผ่าน
