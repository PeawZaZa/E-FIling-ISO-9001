เกณฑ์การยอมรับ

สถานะรหัสเมื่อเมื่อทำต้องได้กรณีการใช้งาน
ยังไม่ได้ทำ AC-01 มี Document Draft ที่กรอก metadata ครบ Document Owner สร้าง/บันทึกเอกสารพร้อมไฟล์แนบ สร้าง document draft และแนบไฟล์ได้สำเร็จ UC-01

ยังไม่ได้ทำ AC-04 Document ถูก obsolete End User ทั่วไปเปิดดูเอกสาร ผู้ใช้ทั่วไปไม่เห็นเป็นฉบับใช้งาน UC-05
ยังไม่ได้ทำ AC-05 มี current document ที่มอบหมายให้รับทราบ End User กดรับทราบ acknowledgement เก็บ user/time/document version ได้ UC-07
ยังไม่ได้ทำ AC-06 มี document_id, finding_id หรือ car_id อย่างน้อยหนึ่งรายการที่ต้องการอ้างอิง ISO User/CAR Owner สร้าง record พร้อมแนบไฟล์ (หนึ่งไฟล์ขึ้นไป) record/evidence ผูกกับ document, finding หรือ CAR ได้อย่างน้อยหนึ่งรายการ และรองรับไฟล์แนบหลายไฟล์ผ่าน RecordFile UC-08
ยังไม่ได้ทำ AC-07 มี evidence หรือ document ที่เกี่ยวข้อง Auditor สร้าง finding finding ผูกกับ evidence หรือ document ได้ UC-09
ยังไม่ได้ทำ AC-08 มี finding ที่ต้องดำเนินการแก้ไข ISO Admin/Auditor เปิด CAR และ CAR Owner ดำเนินการ CAR ผูกกับ finding และมี due date/status/owner ได้ UC-10, UC-11
ยังไม่ได้ทำ AC-09 มีข้อมูล document/ack/CAR/finding ในระบบจริง ผู้ใช้เปิด dashboard dashboard แสดง document status, acknowledgement, CAR status, overdue ได้จากฐานข้อมูลจริง UC-12
ยังไม่ได้ทำ AC-10 มี document ที่เชื่อมกับ record/finding/CAR ผู้ใช้ตรวจสอบ traceability มี traceability จาก document → record/finding/CAR และจาก CAR → evidence —
ยังไม่ได้ทำ AC-11 มีเอกสาร Obsolete ที่เก็บครบ ≥1 Revision หรือบันทึกคุณภาพที่ Retention Clock ครบกำหนด ISO/QA Admin ยื่นคำร้องขอทำลายและได้รับอนุมัติจาก QMR/ผู้อนุมัติ ระบบทำลายเฉพาะรายการที่อนุมัติแล้ว (Hard Delete) และบันทึก Destruction Log ครบถ้วน UC-15
ยังไม่ได้ทำ AC-12 มีเอกสาร Published ที่ถูกเปิด preview/ดาวน์โหลด/พิมพ์ ผู้ใช้เปิดดู/ดาวน์โหลด/พิมพ์เอกสารดังกล่าว ระบบแสดงป้ายกำกับ/ลายน้ำ "สำเนาไม่ควบคุม / Uncontrolled Copy" ทุกช่องทางเสมอ UC-06
ยังไม่ได้ทำ AC-13 End User/Document Owner/Approver มีงาน DAR หรือ Acknowledgement ค้างที่ผูกกับตนเอง ผู้ใช้เปิดเมนู "งานของฉัน (My Task Checklist)" ระบบแสดงเฉพาะงานค้างของผู้ใช้เอง แยกจาก Operational Dashboard รวมของ Group B โดยสมบูรณ์ UC-16
