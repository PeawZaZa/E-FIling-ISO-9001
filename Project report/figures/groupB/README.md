ผู้ช่วย QMR แสดงสิทธิ์ตามการมอบหมายในภาพที่ 4 และระบุหมายเหตุในภาพที่ 5; การอ่านหลักฐานตามสิทธิ์ QMR ในภาพที่ 1 ใช้เงื่อนไขเดียวกัน หัวหน้างานมีเส้น UC-B-09 ตาม Authority Matrix แม้ Supporting Actors ระบุรองคณบดี จึงคงทั้งสองผู้เกี่ยวข้องพร้อมหมายเหตุ ไม่ถือเป็นบทบาทเดียวกัน

UC-B-10 และ UC-B-13 ยังมีถ้อยคำต่างกันระหว่างกฎธุรกิจ ตารางบทบาท และเกณฑ์ยอมรับ จึงแสดงผู้เกี่ยวข้องโดยไม่สรุปจำนวนผู้ลงนามหรือแก้สิทธิ์ใหม่ การสร้างร่าง DAR อัตโนมัติเป็นงานของโมดูล A ไม่เพิ่มวงรี UC ของ B โดยไม่มีรหัสรองรับ

ไม่มีการวาด generalization ระหว่าง Lead Auditor กับ Auditor หรือระหว่างผู้ช่วย QMR กับ QMR เพื่อไม่สื่อว่าสิทธิ์สืบทอดแบบไม่มีเงื่อนไข ผู้ใช้งานระบบในภาพที่ 1 เป็นตัวแทนทุกบทบาทที่ล็อกอิน ไม่ใช่บทบาทฐานข้อมูลใหม่
