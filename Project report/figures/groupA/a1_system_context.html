SRS §2.1 · System Context

ขอบเขตระบบ E-Filing และตำแหน่งของโมดูลควบคุมเอกสาร

โมดูลควบคุมเอกสารที่เอกสารฉบับนี้กำหนดความต้องการแสดงกลุ่มความสามารถภายใน ส่วนโมดูลร่วมอีกโมดูลหนึ่งในระบบเดียวกันแสดงเป็นกล่องบริบทโดยไม่ลงรายละเอียด ลูกศรแสดงทิศทางการอ้างอิงข้อมูล ไม่กำหนดวิธีเรียก โพรโทคอล หรือการพึ่งพาของโค้ด
