# Report Examples

Files in this directory are references only for:

- chapter structure
- section organization
- writing style
- expected level of detail
- presentation style for figures and tables

They are not authoritative sources for E-Filing project facts,
implementation status, requirements, architecture, test results, statistics,
citations or references, or official formatting rules.

## Source priority

1. `docs/REPORT_RULES.md`
   - official report structure and formatting rules
2. Current E-Filing project sources
   - `PROJECT_STATE.md`
   - `SRS_v1.md`
   - architecture documents
   - relevant implementation and tests
3. `docs/report-examples/`
   - writing and organization reference only

If an example conflicts with `docs/REPORT_RULES.md`, follow
`docs/REPORT_RULES.md`. If an example conflicts with the actual E-Filing
implementation, follow verified E-Filing project sources.

Do not copy project-specific facts, results, statistics, citations,
requirements, or implementation details from example reports.

Future report tasks must read only the example relevant to the chapter being
worked on, not all examples.
