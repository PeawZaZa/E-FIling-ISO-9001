# เอกสารความต้องการชุดเดิม (เก็บถาวร)

ย้ายเข้าที่นี่เมื่อ **7 กันยายน 2569**

## ทำไมถึงย้าย

เอกสารความต้องการชุดเดิมมี 6 ฉบับที่เนื้อหาทับซ้อนกันและ **ใช้รหัสคนละชุด** จนอ้างอิงข้ามฉบับแล้วสับสน

- `SRS_A+B.md` ใช้ `FR-A01`–`FR-A16` / `FR-B01`–`FR-B14` / `UC-01`–`UC-16`
- `GroupB_SRS.md` ใช้ `FR-01`–`FR-20` / `NFR-01`–`NFR-07` / `UC-01`–`UC-12`
- รหัส `UC-01` ของสองฉบับ **คนละกรณีการใช้งานกันสิ้นเชิง** (`SRS_A+B.md` = Create Document Draft, `GroupB_SRS.md` = เข้าสู่ระบบ)

จึงตัดสินใจโละทั้งชุดแล้วเขียนเอกสารความต้องการใหม่ทั้งฉบับ

## กติกาการใช้โฟลเดอร์นี้

> **อ้างอิงได้ แต่ห้ามแก้ และห้ามถือเป็นแหล่งความจริง**

ไฟล์ในนี้เก็บไว้เพื่อสอบกลับที่มาของข้อมูลและมติต่าง ๆ เท่านั้น ถ้าจะเขียนเอกสารหรือโค้ดใหม่ ให้ยึด `../Requirements_Carryover.md` ที่รากเป็นตัวตั้ง

## สิ่งที่ถูกลบไปพร้อมกัน

ระบบสอบกลับ `efiling/packages/traceability/` (พร้อม `traceability.yaml`, `efiling/docs/CHECKLIST.md`, `efiling/docs/checklist.html` และคำสั่ง `npm run trace`) ถูกลบทิ้ง เพราะสกัดข้อมูลจาก `SRS_A+B.md` โดยตรงจึงหมดอายุพร้อมกับเอกสารต้นทาง ถ้าต้องการระบบสอบกลับอีก ให้สร้างใหม่จากเอกสารชุดใหม่ ประวัติของเดิมดูได้ใน git

## สิ่งที่ **ไม่ได้** ย้ายเข้ามา

- `Extra details/` — เอกสารต้นทางจากที่ประชุม (BRD, Use Case Spec, Traceability Matrix, ASIS Handbook) ยังอยู่ที่เดิม
- `GroupB_Architecture_Decisions.md` — เป็นเอกสารตัดสินใจสถาปัตยกรรม ไม่ใช่เอกสารความต้องการ
